# OOP Tutorial 1 - Products API

Completed Tutorial 1 project including optional stretch task.

## Requirements
- Java 17+
- Maven

## Run
Open `pom.xml` as a Maven project in IntelliJ IDEA, wait for dependencies, then run `ProductsApiApplication`.

Endpoints:
- http://localhost:8080/hello
- http://localhost:8080/status
- http://localhost:8080/goodbye
- http://localhost:8080/info
- http://localhost:8080/swagger-ui.html

The PDF tutorial uses springdoc 3.1.1. This project uses Spring Boot 4.0.0 with Java 17; dependencies must download before first run.

For submission, create your own GitHub repository and push this project from IntelliJ.
